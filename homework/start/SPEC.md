# SPEC.md

## Requirement

Я хочу, чтобы доска задач не принимала пустые названия, не показывала пустые задачи и правильно считала количество открытых задач.

## Acceptance tests

### R1 — Validation of task titles

- Переименование задачи в пустую строку должно отклоняться.
- Переименование в строку из пробелов, табуляций или неразрывных пробелов (U+00A0) должно отклоняться.
- При отклонении прежнее название задачи должно сохраняться.
- Пробелы в начале и конце непустого названия должны обрезаться.

### R2 — Hide blank tasks

- Доска не должна отображать задачи, название которых состоит только из пробельных символов.
- Это правило должно применяться и к задачам, которые были сохранены до исправления.

### R3 — Correct open task counter

- Счётчик «Открытых» должен учитывать только незавершённые задачи с непустыми названиями.
- Пустые задачи не должны увеличивать значение счётчика.

## Non-goals

- Не изменять дизайн доски.
- Не добавлять новые функции управления задачами.
- Не менять способ хранения задач.
- Не добавлять сторонние зависимости.

## Files in scope

- `src/tasks.ts`
- `src/App.tsx`

## Definition of done

- Все acceptance tests проходят.
- Пустые задачи не отображаются.
- Счётчик открытых задач показывает правильное значение.
- Переименование в пустое название отклоняется.
- `npm test` проходит успешно.
- `npm run build` завершается успешно.
- Изменения ограничены разрешёнными файлами.

## Дополнение: обработка символа нулевой ширины

- Строка, состоящая только из символов U+200B, считается пустой.
- Символы U+200B в начале и конце непустого названия обрезаются.
